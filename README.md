# RailGuide 360
## Smart Railway Station Indoor Navigation System

### SIH Problem Statement 1710

RailGuide 360 is a smart indoor navigation system designed to
help railway passengers easily locate and reach different
facilities inside railway stations.

The system provides interactive station maps, step-by-step
navigation, accessibility-friendly routes, voice guidance,
real-time facility information and digital kiosk support.

## Problem

Large railway stations contain multiple platforms,
ticket counters, restrooms, waiting areas, food courts,
lifts, escalators and other facilities.

Passengers who are unfamiliar with the station may find it
difficult to locate their destination quickly.

This can lead to confusion, unnecessary walking,
crowding and delays.

Therefore, an easy-to-use indoor navigation system is required.
# Proposed Solution

RailGuide 360 is a multi-platform railway station navigation
system that helps passengers find facilities and destinations
inside railway stations.

The system uses a digital station map and a navigation engine
to calculate suitable routes based on the passenger's selected
destination.

Passengers can access the system through a mobile application
or digital kiosk.

The system also provides accessibility-friendly routes,
voice guidance and real-time facility updates.
# Features

## 1. Interactive Station Map
Displays platforms, ticket counters, restrooms, food courts,
waiting areas, lifts, escalators and entrances.

## 2. Step-by-Step Navigation
Provides directions from the passenger's current location
to the selected destination.

## 3. Accessibility Navigation
Provides wheelchair-friendly routes and avoids stairs when
required.

## 4. Voice Guidance
Provides voice-based navigation for visually impaired
passengers.

## 5. Real-Time Updates
Displays changes such as platform changes, temporary closures
and facility availability.

## 6. Digital Kiosk
Passengers can use touch-screen kiosks installed inside
the station.

## 7. Emergency Navigation
Helps passengers locate emergency exits, medical facilities
and help desks.

## 8. Admin Dashboard
Railway staff can update station information, routes and
facility status.
